# Simpli Charity Activation Prototype

An interactive prototype of the Simpli charity activation flow, built with React and Vite.

## Screens

1. Post call landing: value first welcome that shows potential impact before asking for data
2. Document upload: three documents instead of a long form, with a progress indicator
3. Charity dashboard: a match readiness score that gamifies profile completion
4. Donation match: just in time data collection to accept a matched donation
5. Impact report: retention screen with impact totals and photo upload

## Running locally

```
npm install
npm run dev
```

## Build

```
npm run build
```
